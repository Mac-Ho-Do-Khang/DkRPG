Unreal Engine

A brief introduction to Unreal Engine. The engine itself offers an insanely wide range of features, and it would be impossible to discuss all of them in this document, nor would it be in any existing documentation for that matter. However, for a more comprehensive overview of Unreal Engine, please refer to the official documentation.

Unreal Engine is a 3D computer graphics game engine created by Epic Games. It was first developed for the 1998 first-person shooter game Unreal. Although it began as a tool for PC first-person shooters, it has since been used across many different game genres and has expanded into other fields, especially film and television production. Written in C++, Unreal Engine is highly portable and supports a wide range of platforms, including desktop computers, mobile devices, consoles, and virtual reality systems.

Logo used since 2023

Unreal Engine 1 was developed in 1995 by Epic Games founder Tim Sweeney for the game Unreal. It supported both software rendering and hardware rendering through early 3D accelerators such as the 3DFX Voodoo Graphics using the Glide API. The engine ran on Windows, Linux, Mac, and Unix systems. Epic later began licensing it to other game studios.

Unreal Engine 2 marked the shift from software rendering to full hardware rendering. It also added support for consoles including the PlayStation 2, Xbox, and GameCube. The first game built with UE2 was released in 2002, and the engine received updates until 2005.

Unreal Engine 3 introduced support for multithreading, allowing better performance on modern hardware. It used DirectX 9 as its primary graphics API, which helped simplify rendering. The first games using UE3 were released in late 2006.

Unreal Engine 4 introduced physically based materials and the Blueprints visual scripting system, making development more accessible. The first UE4 game was released in April 2014. This version was also the first to be free to download, with Epic Games earning revenue through royalties on game sales.

Unreal Engine 5 introduced major technologies such as Nanite, which enables extremely detailed geometry with automatic level of detail, and Lumen, a system for dynamic global illumination and reflections using ray tracing techniques. It was announced in May 2020 and officially released in April 2022.

Today, Unreal Engine powers many high-profile AAA titles across diverse genres, including:

  • Fortnite: A Battle Royale game that has become a cultural phenomenon, attracting millions of players worldwide. It features a constantly evolving world with regular updates and events, showcasing the engine's ability to support large-scale multiplayer experiences.
  • Paragon: A MOBA game that was eventually cancelled, it served as a testing ground for the Gameplay Ability System and demonstrated the engine's capabilities in handling complex character interactions and multiplayer mechanics.
  • Black Myth: Wukong: An Action RPG based on the classic Chinese novel "Journey to the West". It features stunning visuals and intricate combat mechanics, showcasing the engine's ability to create immersive single-player experiences.
  • Lords of the Fallen: An Action RPG that emphasizes challenging combat and deep character customization. It demonstrates the engine's versatility in creating dark fantasy worlds and engaging gameplay.

Beyond commercial titles, Epic does release prominent, complete sample projects as open-source resources freely available on the Unreal Engine Marketplace. These projects can be explored thoroughly and serve as invaluable references, significantly easing the learning journey for newcomers. Notable examples include:

  • Action RPG: An UE4 sample demonstrating how to build a high-end mobile Action RPG for both Android and iOS.
  • Lyra Starter Game: An UE5 multiplayer shooter project built around the Gameplay Ability System, designed as a starting point for production games.
  • Valley of the Ancient: An UE5 showcase highlighting the rendering capabilities of Nanite, Lumen, and other next-generation features.
  • Slay Animation Sample: A sample project focused on animated content, demonstrating high-quality character animation workflows.
